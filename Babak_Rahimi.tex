\cvsection{Selected Projects}

\textbf{MPPT Solar Charger}\\
\textit{B.Sc. Project \,|\, 2025--2026}
\begin{itemize}
  \item Designed a buck-converter charger, including topology and component selection,
        circuit design, PCB layout, and ATmega8A PWM firmware.
  \item Simulated the design in LTspice and tested the prototype under load and with a
        solar panel.
  \item Developed a Python application to monitor input/output voltage, current, power,
        and efficiency, with FFT analysis.
\end{itemize}
\divider

\textbf{USB Oscilloscope}\\
\textit{Personal Project \,|\, 2026--Present}
\begin{itemize}
  \item Built a prototype around the STM32F103RET6 internal ADC and USB data transfer.
  \item Achieved approximately 1 MSPS, limited by USB throughput; developed PC-side
        signal visualization.
\end{itemize}
\divider

\textbf{USB-Controlled Function Generator}\\
\textit{Personal Project \,|\, 2026--Present}
\begin{itemize}
  \item Used an AD9833 for signal generation up to 1 MHz and the microcontroller's
        internal DAC for lower frequencies.
  \item Implemented USB communication for computer-based control.
\end{itemize}
\divider

\textbf{Computer-Controlled Laboratory Power Supply}\\
\textit{Personal Project}
\begin{itemize}
  \item Developed a dual-output adjustable supply (0--30 V, up to 3 A), with fixed
        3.3 V and 5 V rails.
  \item Adapted a buck-converter design to enable accurate computer control of the
        adjustable outputs.
\end{itemize}
\divider

\textbf{Capacitive-Touch Keyboard}\\
\textit{Personal Project}
\begin{itemize}
  \item Designed the PCB and complete microcontroller firmware using TTP223
        touch-sensor ICs and standard logic ICs.
\end{itemize}
\divider

\textbf{Textile Inspection Data Logger}\\
\textit{Industrial Project}
\begin{itemize}
